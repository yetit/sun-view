# Здания без этажности — список для обхода / Buildings missing floor counts

Сгенерировано `npm run levels -- <город>` (входит в `npm run fetch`). В OpenStreetMap скрипт ничего не правит: правки делает человек — на месте, через StreetComplete, MapRoulette или JOSM.

Generated by `npm run levels -- <city>` (part of `npm run fetch`). The script never edits OpenStreetMap: people do, on site, with StreetComplete, MapRoulette or JOSM.

## Как выбран порядок / How the order is chosen

Для каждого дома без `building:levels` и `height` дом временно поднимается с 1 до 4 этажей, и для соседей в радиусе 100 м пересчитываются часы солнца в день зимнего солнцестояния и вид на море (8 направлений) на их среднем этаже. `neighbours_affected` — у скольких соседей меняется ответ (солнце на ≥ 0,5 ч или хотя бы одно направление с морем), `winter_sun_hours` — сколько часов зимнего солнца у соседей в сумме зависит от этажности, `sea_directions` — сколько направлений с морем. Сортировка: по `neighbours_affected`, затем по часам, затем по морю. `priority`: high — 6 и больше соседей, medium — 3–5, low — 1–2. Метрика — `src/scripts/levels.ts`.

For each building without `building:levels` and `height`, the building is temporarily raised from 1 to 4 floors, and for neighbours within 100 m we recompute winter-solstice sun hours and the sea view (8 directions) on their middle floor. `neighbours_affected` is how many neighbours get a different answer (sun by ≥ 0.5 h, or at least one sea direction), `winter_sun_hours` is the total winter sun of the neighbours that depends on this building, `sea_directions` the same for sea directions. Sorted by `neighbours_affected`, then hours, then sea. `priority`: high for 6+ neighbours, medium for 3–5, low for 1–2. The metric lives in `src/scripts/levels.ts`.

## MapRoulette

1. Create a challenge, source "Upload GeoJSON", file `<city>.geojson` (one task per building; geometry is the footprint, the OSM object is in `@id`).
2. Set "OSM id property" to `@id` so tasks link to the building, and priority rules on the `priority` property (high / medium / low).
3. Instruction (one for the whole challenge; `{{label}}` and `{{osm_url}}` are filled per task):

> Add `building:levels` — the number of above-ground floors — to {{label}} ({{osm_url}}). Use only what you have seen on site or on street-level imagery with a compatible licence (Mapillary, Panoramax). Do not guess from shadows or satellite images. If you can't tell, skip the task.
>
> Укажите `building:levels` — число надземных этажей — для {{label}} ({{osm_url}}). Только то, что видели на месте или на уличных фото с подходящей лицензией (Mapillary, Panoramax). Не угадывайте по теням и спутнику. Не видно — пропустите задачу.

`<city>.csv` — первые 100 домов для прогулки с телефоном / the top 100 for a walk with a phone.
