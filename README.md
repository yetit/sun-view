# Sun & View

Прототип: кликаешь здание на 3D-карте Тивата, выбираешь этаж — и видишь, сколько часов в день солнце попадает в окна по четырём сезонам (равноденствия и солнцестояния) и видно ли море из окна по каждому из восьми румбов. Всё на открытых данных, расчёт полностью в браузере, бэкенда нет.

```bash
nvm use          # Node ≥ 22.22 (.nvmrc → 24)
npm install
npm run dev      # http://localhost:4325
```

## Стек

- Astro 7, одна страница `src/pages/index.astro`.
- MapLibre GL 6: `src/scripts/style.ts` — светлая карта с рельефом, `src/scripts/main.ts` — карта, выбор здания, панель.
- MapLibre 6 ищет воркер рядом со своим модулем, Vite этот путь ломает: `scripts/copy-maplibre-worker.mjs` (predev/prebuild) копирует воркер в `public/maplibre/`.
- `suncalc` — положение солнца.
- Ключи API не нужны.

## Данные

Лежат в `data/<город>/`, коммитятся; сайт в рантайме внешние API не дёргает. Обновить: `npm run fetch`.

| Что | Откуда | Лицензия | Скрипт |
| --- | --- | --- | --- |
| Контуры зданий, `building:levels`, `height` | OpenStreetMap через Overpass API | ODbL, © участники OSM | `scripts/fetch-buildings.mjs` → `buildings.json` (GeoJSON) |
| Рельеф для расчёта | [Copernicus DEM GLO-30](https://registry.opendata.aws/copernicus-dem/) с AWS Open Data (COG-тайлы 1°×1°, читается только окно bbox range-запросами) | © DLR / Airbus, предоставлено ЕС и ESA в рамках Copernicus, свободно с указанием источника | `scripts/fetch-dem.mjs` → `dem.json` (Int16 в base64, 2″ ≈ 60 м) |
| Рельеф и подложка для показа | [Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (terrarium), [OpenFreeMap](https://openfreemap.org) / OpenMapTiles | открытые | в стиле карты |

Тиват на 2026-10-16: 3 625 зданий, у 495 известна этажность или высота.

## Как считается

Локальная система — метры от центра города; высоты — над уровнем моря. `src/scripts/grid.ts`:

- **Здание**: центроид контура, отметка земли из DEM, высота = `height`, иначе `levels × 3 м`, иначе 2 этажа (такие здания на карте светлее, а в панели помечены). Окно — на середине высоты выбранного этажа.
- **Растр крыш**: все здания растеризуются в сетку 6 м с абсолютной отметкой кровли и индексом здания — так луч проверяет соседей за O(1) на шаг.
- **Солнце** (`src/scripts/analysis.ts`): для каждого сезона с шагом 10 минут берём `SunCalc.getPosition`; если солнце над горизонтом, пускаем луч из окна по азимуту и высоте солнца: шаг 3 м до 1 км (здания + рельеф), дальше 30 м до 15 км (только рельеф). Луч упёрся в крышу чужого здания или в рельеф — тень. Часы солнца = доля освещённых отсчётов. Берётся здание целиком, без привязки к стороне фасада: «солнце попадает хоть в какие-то окна этажа».
- **Море**: по каждому из 8 румбов идём вдоль луча с уровня окна, держим максимальный угол места препятствий (рельеф, крыши). Ячейка воды (DEM ≤ 0) видна, если угол на неё выше всех препятствий до неё — так дальняя вода видна поверх низкого берега. Результат — расстояние до первой видимой воды, на карте рисуется лучом (зелёный/красный).

Допущения и ограничения:

- Copernicus DEM — модель *поверхности* (DSM), в ячейку попадают и крыши, и деревья. Под зданием берётся минимум из четырёх ближайших ячеек; своя ячейка DSM при трассировке пропускается. На набережной земля может уйти в 0.
- Шаг 2″ (≈60 м) и bbox рельефа из конфига; за пределами сетки луч считается свободным — для Тивата bbox покрывает Врмац и Луштицу, Ловчен частично.
- Море = ячейки DEM с высотой ≤ 0; озёра и низкие луга тоже попадут в «воду».
- Сутки считаются по UTC (полоса в панели), время восхода и заката переведено в часовой пояс города.
- Этажность по OSM известна у ~14 % зданий Тивата; остальные — 2 этажа по умолчанию.

## Другой город

Всё в `city.config.mjs`: id, bbox зданий (по нему и растр крыш), bbox и шаг рельефа, центр камеры, часовой пояс, высота этажа. Поменять, запустить `npm run fetch` — данные лягут в `data/<id>/`, приложение подхватит их по id. Для места вне покрытия Copernicus (его нет только у части островов) надо заменить `fetch-dem.mjs`.
